Reset Account

Resets your Learning Language Database back to its initial state (default word list). This cannot be undone.

Clean Up Duplicates

Scans Learn, Learning, and Learned for the same word appearing more than once (in one list or spread across several) and removes the extras. When a word exists in more than one list, the copy in Learning is kept (or Learned if the word only exists in Learn + Learned). This cannot be undone.

Delete Account
